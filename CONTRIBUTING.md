# Contributing

Thanks for checking out my learning projects! While these are mainly for my own practice, if you find something useful or want to suggest improvements, feel free to contribute.

## How to Contribute

1. **Fork the repo**
2. **Create a branch** for your changes
3. **Make your changes**
4. **Test everything** - make sure all projects still build and run
5. **Submit a pull request**

## What I'm Looking For

- Bug fixes (if you spot any)
- Better explanations in the README files
- Code improvements that make things clearer
- Additional examples or use cases

## What to Keep in Mind

- These are learning projects, so keep things simple and well-documented
- Follow the existing code style
- Add comments explaining what you changed and why
- Update the relevant README if needed

## Project Structure

Each project is self-contained with its own:
- Database setup script
- README explaining what it does
- All necessary code files

## Building the Projects

1. Open `Taska.sln` in Visual Studio 2026
2. Restore NuGet packages (VS does this automatically)
3. Build the solution (Ctrl + Shift + B)
4. Run the database setup scripts for projects you want to test

## Questions?

Feel free to open an issue if you have questions or suggestions!
